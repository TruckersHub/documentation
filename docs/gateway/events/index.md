# Gateway Events

Gateway messages use a common envelope containing `type` and `data`. The current documented gateway message types are listed below.

- [AUTH](./authentication)
- [AUTH_ACK](./auth-acknowledgement)
- [PLAYER_DATA](./player-data)
- [PLAYER_ONLINE](./player-online)
- [PLAYER_OFFLINE](./player-offline)
- [NEW_EVENT](./new-event)
