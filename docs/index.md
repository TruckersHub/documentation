# TruckersHub Developers

Build applications, dashboards, integrations, and real-time services using the TruckersHub developer platform.

TruckersHub collects telemetry from Euro Truck Simulator 2 and American Truck Simulator through the SCS SDK plugin and makes parsed data and events available to virtual trucking companies.

## Developer Platform

- **REST API** — Access and manage TruckersHub data.
- **Gateway** — Receive live data through a secure WebSocket connection.
- **Webhooks** — Receive event notifications over HTTP.
- **Discord** — Configure Discord Rich Presence and future Discord integrations.
- **Objects** — Reference the JSON data structures returned by TruckersHub.
