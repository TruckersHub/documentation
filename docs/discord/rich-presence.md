---
title: Discord Rich Presence
---

To customise your Discord Rich Presence, you will need to create an application on the [Discord Developer Portal](https://discord.com/developers/applications). Once you have created the application, head over to the TruckersHub [integrations -> discord](https://truckershub.in/integrations).

Then, enter the application id of the application you created into the ETS2 Application ID and ATS Application ID (it is possible to have a different application id for each game).

# Setup Logo

Now that you have configured your Discord Rich Presence, you can change the logo by uploading a Rich Presence Assets under the Discord Developer Portal. The name of this asset must be `logo` and can be one of the supported file formats.
