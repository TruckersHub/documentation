## User's Following Activities Data

You can get User's activities Data by making a `GET` request to `https://api.truckershub.in/v1/socials/:steamID`. You will need to replace `:steamID` with the User's SteamID64.

After a successfully call an array of the [Activity Object](/typedefs/activity-object) will be returned.
