---
title: First API Request
---

You are now ready to do your first request!

To make sure everything is working you can use the `me` endpoint. This API endpoint will return you VTC Information.

Try it out by sending a `GET` request to `https://api.truckershub.in/v1/me`. This will return you the [VTC Object](/typedefs/vtc-object)

If you got a response that looks like [VTC Object](/typedefs/vtc-object) then congratulations! You have successfully authenticated and performed a request to the TruckersHub API!

If you got an error, make sure you are sending a valid authorization token in the header of the request.
