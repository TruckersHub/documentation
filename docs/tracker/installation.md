---
title: Tracker Installation
---

You'll need to download the TruckersHub Client. It may be downloaded at: [https://truckershub.in/download](https://truckershub.in/download)

This link is a permanent link. This will always update with the latest version of our client. Feel free to copy this link and use it for your purposes instead of downloading it.

Our Tracker requires VC Redist package from Microsoft if you don't already have it installed. Please install it using the link here: [https://aka.ms/vs/17/release/vc_redist.x64.exe](https://aka.ms/vs/17/release/vc_redist.x64.exe).

Note:-  
When TruckersHub Client is installed the game will show a prompt every time it is started. This popup asks for permission to use SCS SDK which TruckersHub Client uses to get data from the game.
