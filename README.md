## 📚 About

This repository contains the source code for the TruckersHub Developer Documentation.

The documentation covers everything developers need to integrate their applications with TruckersHub.

### Available Documentation

- **API** — Access TruckersHub data through the REST API
- **Gateway** — Receive real-time TruckersHub data through WebSockets
- **Webhooks** — Receive event notifications in your application
- **Discord** — Integrate TruckersHub with Discord
- **Type Definitions** — Reference TruckersHub data structures

## 🚀 Developer Platform

### API

The TruckersHub REST API allows applications to interact with supported TruckersHub resources.

The API provides access to areas including:

- Drivers
- Jobs
- Routes
- Driving Academy
- Statistics
- Live Data
- Skills
- Simulation System
- Events
- Event Slots
- Notifications
- Socials
- Sessions

API Base URL:

```text
https://api.truckershub.in/v1
```
